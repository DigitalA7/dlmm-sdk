# Produit et périmètre

Meteora DLMM fournit un SDK pour intégrer un market maker automatisé à liquidité discrétisée. Le dépôt rassemble clients TypeScript et Python, utilitaires Rust, artefacts et interfaces IDL. Le programme on-chain et ses comptes sont abordés à travers les interfaces publiques et les instructions exposées.

Ce parcours distingue le SDK d’une application complète et décrit ce que l’intégrateur doit vérifier lui-même.
