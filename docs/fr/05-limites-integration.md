# Limites et intégration

Le dépôt documente le SDK public et les interfaces d’intégration de DLMM. Le programme lb_clmm n’est pas entièrement publié comme source contractuelle : les clients s’appuient sur l’IDL, les comptes on-chain et les API documentées.

Ce parcours n’installe rien, ne compile rien et n’exécute aucun test. Les versions de clients, le cluster, les limites de débit et la fraîcheur des données doivent être vérifiés séparément.
